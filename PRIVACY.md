# Privacy Policy for Douyin Live Chat Suffix Helper

Last updated: June 4, 2026

We value your privacy. This Privacy Policy explains how our Google Chrome extension ("Douyin Live Chat Suffix Helper" / "抖音直播发言自动后缀") handles information.

## 1. No Data Collection
The extension does **not** collect, store, transmit, or share any personal data, browsing history, or chat message contents. 

## 2. Permissions Used
- **`storage`**: Used solely to save and load your custom configuration locally (i.e., whether the suffix is enabled and what custom suffix text you set).
- **Website Access (`live.douyin.com`)**: Used solely to run the content script locally on the page to intercept the chat box submission (Enter key or Send button click) and append your custom suffix text locally before it is sent.

## 3. Data Processing and Transmission
All text processing and settings operations are executed entirely on your local device within the browser sandbox. No data is sent to external servers or third parties.

## 4. Updates to This Policy
We may update this policy from time to time. Any changes will be posted directly on this page.

## 5. Contact
If you have any questions, please open an issue in the GitHub repository: https://github.com/asadman1523/douyin-live-chat-suffix
